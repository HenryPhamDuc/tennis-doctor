About this bibliography: Tennis Doctor draws its answers from two sources — Henry Pham's Vietnamese tennis research vault (20,080 curated articles) and a curated sample from the tennis instruction books listed above (2,412 chunks across 97 books). Each book contributes roughly 25 evenly-spaced samples to the vector database, balanced across categories so the chat bot can answer questions on any aspect of tennis.

Books are extracted with pymupdf, chunked at paragraph boundaries (~1,000 chars each), and embedded with Cloudflare's multilingual bge-m3 model. Retrieval uses cosine similarity over 1024-dimensional vectors stored in Cloudflare Vectorize. The system prompt instructs the LLM to cite sources by number.
